# Defunct interfaces

`legacy-frontend/` is the complete pre-workbench React interface preserved from
the frozen R22/V10 source at commit
`4039045128d581416fcad61e8e8572d52df7b558`.

It is retained for reference and recovery only. The build and runtime scripts
serve the model workbench from `../frontend/`; nothing in this directory is
part of the presentation build.
