# Data Audit

## Data Decision

Gate 2 uses no external dataset. Every state, priority, shock, dependency, and transition coefficient is authored synthetic data under CC0-1.0 for this repository. The API and UI permanently expose `empirical: false` / `Synthetic model`. No result is a forecast of a real city.

## Deterministic Sources

| Source | Revision / provenance | Runtime availability |
|---|---|---|
| Dynamics and shock catalogue | `synthetic-city-dynamics-v1` in `backend/app/simulator.py`; authored 2026-07-14 | Source code, offline |
| Random schedule | NumPy 2.3.2 `Generator(PCG64)`; entire horizon generated before either planner | Locked in `uv.lock`, offline |
| Frozen candidate | Generated by `scripts/build_policy_artifact.py`; 56 weight vectors, five synthetic calibration scenarios | 722-byte tracked JSON, offline |
| Artifact lock | `artifacts/manifest.lock.json` | SHA-256 checked for every readiness and comparison call |

Frozen policy SHA-256: `23762a44d67e83dd487558d595d3d9ed5f5e406915f488a076ac21190ab9a6e3`.

## Split And Leakage Controls

The split unit is a complete scenario plus seed, never a day. Artifact selection sees only five synthetic scenarios with seeds `8100..8104`. The fixed Gate 2 fixture (`424242`) and runtime unseen fixture (`118773`) are absent from the generator. The policy artifact is frozen and loaded before evaluation; it cannot update from requests. Both planners consume the identical precomputed shock objects and neither receives future shocks when computing today's proposal.

This is a structural holdout proof, not a statistically meaningful generalization study. Five calibration scenarios and two evidence fixtures are too small for a performance claim.

## Bounds

- Horizon 7-30 days; budget 50-500 units/day
- Five initial services .05-.95; five priorities .5-2.0
- Daily shock probability 0-.35
- Severity minimum .05-.25; maximum .10-.40 with minimum strictly below maximum
- Optional forced shock must fall inside the horizon

Pydantic rejects unknown fields, wrong vector lengths, invalid bounds, and inconsistent severity or forced-day values.
